# Dashboard Realisasi Tambahan TKD 2026

Dashboard realisasi Tambahan TKD 2026 Pemerintah Kabupaten Solok. Halaman ini membaca Sheet1 dari Google Spreadsheet "TKD Tambahan Realisasi Per 14112026" setiap kali dibuka, lalu otomatis membaca ulang tiap 10 menit.

- Tampilan: https://ekabs165.github.io/kantorkoe-ebs165/
- File utama: `index.html` (satu file, tanpa instalasi)
- Link sumber data ada di bagian `PENGATURAN` di atas `index.html` (`SUMBER_DATA`).

Spreadsheet harus dibagikan dengan akses "Siapa saja yang memiliki link: Pelihat". Kalau spreadsheet gagal dibaca, dashboard menampilkan data cadangan per 16 November 2026.
